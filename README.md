# icon-generator

The Command-Line Icon Generator is a simple application that allows users to create a custom SVG logo through command-line inputs. It leverages Inquirer for user input and Jest for unit testing. Users can customize the text, text color, shape, and shape color, resulting in a unique logo saved as icon.svg.

Features
Accepts user input for text (up to three characters)
Allows selection of text color (via color keywords or hexadecimal values)
Presents a list of shapes to choose from: circle, triangle, square and ellipse
Allows selection of shape color (via color keywords or hexadecimal values)
Generates an SVG file named icon.svg
Outputs confirmation message in the command line upon creation of the SVG file
